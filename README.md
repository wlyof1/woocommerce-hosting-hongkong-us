## 先分清：你要的是“放网站”还是“放身份”

放网站，服务器必须能开 80 和 443 端口，否则域名解析过去，浏览器连不上。SixtyNet 的住宅系列产品页写得很直白：

> “Due to IP risk control reasons, residential IP products do not open ports 80&443.”
> 因 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。

这意味着 Residential-STARTER 那 $260/年 买回来，装不了 WordPress，也挂不了任何对外网站。它的价值在另一端：IP 在多个数据库里被判为原生美国地址、双 ISP 住宅属性，平台风控和流媒体识别的结果比普通机房 IP 好得多。2025 年 10 月的一篇第三方测评测过 SixtyNet 的 Cox 双 ISP 住宅 VPS，确认官方屏蔽 PING 与 80/443 端口，IP 属性判定为“原生美国 IP、家宽属性、纯净无风险”。做平台账号环境、广告账户、多地区访问验证的人要的是这个。

外贸建站用不上这部分。你需要的是能长时间跑 PHP 和 MySQL、有防御、带宽够的机器，也就是下面这条线。

## 机房：放香港还是美国

客户在欧美，选洛杉矶；客户在东南亚，或者你自己在国内天天开后台改内容，选香港。两地延迟差一个数量级。

香港机房到国内主要城市约 10-30ms，洛杉矶到国内通常 140-200ms。晚高峰是分水岭：走 CN2 GIA 的洛杉矶线路，第三方测评数据显示北京时间 21 点仍能稳定在 140-160ms、丢包接近零；同配置走普通国际线路的机器，国内用户首屏可能要等 4-5 秒。

SixtyNet 官网当前 VPS 页面展示的套餐全部在洛杉矶，没有香港节点。客户以东南亚为主、或者国内后台必须秒开，这一条就直接出局了，不用再算配置。

带宽口径也要一起看。香港机房的带宽单价明显高于美国，同样预算能买到的口子小很多。美国机房的百兆到 Gbps 级别是常规配置，SixtyNet 的 LAX 系列标的起点就是 2Gbps。纯展示站加询盘表单，几 Mbps 的香港小带宽也够用；站上有大量产品图、样册下载、演示视频，美国的大带宽更省心。

备案这一项可以放心：香港和美国服务器都不需要备案，只有中国大陆机房要求备案。

## 2核2G 够不够：按产品数和月流量算

配置梯度大致是这样：

- 纯静态页或轻量 WordPress：1核1G 够用
- WordPress + WooCommerce，产品数小于 1000：2核2G 起步
- 产品数超过 5000，或有复杂筛选、多语言多币种：4核4G 以上
- 一台机跑 3-5 个小站：4核4G 起

流量按页面体量估：50-100 个产品页，每页 2-3MB，日均 200 次访问，一个月大约 50-80GB。图片多、带视频的话翻倍，也就 150-200GB。

所以 LAX-STARTER 的 5TB 月流量对外贸站基本是过剩的。你真正需要掂量的是内存和 IO，不是流量。这也意味着 LAX-STARTER 到 LAX-MICRO 那 $200/年 的差价，买的是 CPU 从 2 核到 4 核、内存 2G 到 4G、网络 2Gbps 到 4Gbps、流量 5TB 到 10TB。产品数不到 1000、没装几十个插件的话，这 $200 可以省下来。

什么时候该上 MICRO：产品数过 2000、同时开了多语言和多币种、装了页面构建器加多语言加会员这类重型插件组合，或者同一台机上跑两三个站。

## 下单前必须确认的四件事

**退款条款。** SixtyNet 的 AS9929 住宅系列页面写明退款只退到网站余额，LAX 系列页面没有标注退款政策。开工单问清楚：几天内可退、退到哪里、有没有流量消耗限制。这条行业里差别极大：DMIT 是 3 天内可退，限 30GB 流量以内；ZoroCloud 部分系列给 24 小时退款，特价套餐只退余额；Hostease 的独立服务器开通即不退不换。

**流量用尽怎么处理。** SixtyNet 页面只写了额度，没写超了是限速还是按量计费。DMIT 的做法是限速到 100Mbps-1Gbps 但不断线。这条不问清楚，某个月图库被爬一遍就可能收到意外账单。

**端口。** 住宅系列不开 80 和 443，这是产品设计，不是配置能改的。

**密码和备份。** 用 12 位以上、含大小写字母和符号的密码，部分商家扫到弱密码会直接关机甚至删机且不退款。官网页面没有提到快照和自动备份，按“没有”准备，自己在机器上配定时备份到本地或对象存储。

## FAQ

**外贸建站服务器需要备案吗？**
香港和美国机房都不需要，只有中国大陆机房要求备案。

**1G 内存能跑 WordPress 吗？**
轻量 WordPress 配 Nginx 和缓存插件，1G 够。装 WooCommerce 建议 2G 起，插件多、产品多的时候 1G 容易内存溢出，站点直接挂掉。

**SixtyNet 的机器能装 WordPress 和 WooCommerce 吗？**
LAX 系列是标准 VPS，可以装任意系统和建站程序，WordPress、WooCommerce、OpenCart 都能跑。住宅系列不行，端口关着。

**支持支付宝吗？有中文客服吗？**
官网当前的 VPS 页面没有列出支付方式和支持语言，结账页会显示可选渠道，下单前在自己的账单页确认一遍。

**月流量 5TB 是什么概念？**
50-100 个产品页、每页 2-3MB、日均 200 次访问，一个月约 50-80GB。图片多或有视频翻倍，也在 200GB 以内。5TB 对绝大多数外贸站是过剩的。

**香港和美国的价格差多少？**
同样配置下香港通常更贵，而且带宽口径小得多。香港机房的价值在延迟（10-30ms），不在流量和带宽。
